Bulk import / export (CSV)

Export the current catalog, edit it in a spreadsheet, then import it back — a row whose product code + unit already exists updates that product's name/variant/price; a new combination adds it to the catalog with zero stock everywhere, same as adding one by hand. Unit can be a bottle size or BULK (a BULK row is added as Bulk/Refill). A new size for a code that already has other sizes on file takes that product's existing name and variant, so a typo in one row can't rename it differently across its own sizes.
